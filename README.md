# Indrajitsinh Rathod — Personal Portfolio

A responsive, premium dark-themed portfolio built with plain HTML, CSS, and JavaScript. It includes experience, selected projects, a dedicated AI/GenAI section, contact details, and a résumé PDF.

## Files
- `index.html` — page content and sections
- `styles.css` — styling, responsive layout, cards, and animations
- `script.js` — mobile navigation and scroll reveal
- `assets/Indrajitsinh_Rathod_Resume.pdf` — résumé linked from the page

## Preview locally
Open `index.html` in a browser. Internet access is used for Google Fonts; the rest is local.

## Before publishing
1. Review all résumé content, dates, and metrics.
2. Replace the generic GitHub link in `script.js` with your real GitHub profile if you want to display it.
3. Confirm each project link is still active and that public descriptions are okay to share.
4. If desired, add screenshots, GitHub repository links, or more detailed case studies to the project cards.
5. Check the site on desktop and mobile.

## Publish free with GitHub Pages
1. Sign in at https://github.com/.
2. Create a public repository named `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**, choose branch `main` and folder `/(root)`, then save.
6. After deployment, visit `https://YOUR-GITHUB-USERNAME.github.io/`.

Official instructions: https://docs.github.com/en/pages/quickstart

## Alternative hosting
You can also import the repository into https://vercel.com/ and deploy as a static site. No build command is needed.

A custom domain is optional and usually costs money; start with the free GitHub Pages address.
